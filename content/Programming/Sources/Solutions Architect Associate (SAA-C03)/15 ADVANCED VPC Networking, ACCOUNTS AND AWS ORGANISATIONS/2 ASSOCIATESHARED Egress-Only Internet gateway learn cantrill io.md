In the absence of any other filtering, the IPv6 instance will be exposed to the public internet. So since NAT isn't usable with IPv6, we have a functionality hole. The ability to use the IPv6 instance to connect to the public internet. The ability to connect out but not allow networking connectivity to be initiated in an inbound direction. With normal internet gateways, all IPv6 instances from a networking perspective can connect out and things are capable of connecting into them.
