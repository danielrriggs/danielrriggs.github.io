## AWS Local Zones
Part of the AWS global network, specifically the Edge network.
**AWS Without Local Zones**
![[AWS Without Local Zones.png]]

**AWS With Local Zones**
![[AWS With Local Zones.png]]
Local Zones have private networking with the parent region.
- "1" zone - no built in resilience
- Think of them **like an AZ**, but **near your location**
- They are **closer** to you ... so **lower** latency.
- Not all products support them .. many are opt in w/ limitations
	- // for more info & updates - [AWS Local Zones Features - AWS](https://aws.amazon.com/about-aws/global-infrastructure/localzones/features/)
- DX to a local zone IS support (extreme performance needs)
- Utilize **parent region** .. i.e. **EBS snapshots** are TO parent
- Use local zones when you need **THE HIGHEST** performance
