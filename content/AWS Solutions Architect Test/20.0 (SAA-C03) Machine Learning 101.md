## Amazon Kendra
// More info - [What is Amazon Kendra? - Amazon Kendra](https://docs.aws.amazon.com/kendra/latest/dg/what-is-kendra.html)

- **Intelligent search** service
- .. designed to **mimic** interacting with a **human expert**

	- This keeps the index current with the original data source

- Integrates with AWS Services (**IAM**, **Identity Center** (SSO), ...)

## Amazon Lex
Backend service. Use to add capabilities to your app.

- **Text** or **Voice** **conversational** interfaces
- **Powers** the **Alexa** service
	- // Remember 'Lex' for voice, as in, 'Lex' in Alexa.
- Automatic speech recognition (**ASR**) - speech to text
	- // (opinion) Apple's Siri (voice assistant) is worse than Lex because it doesn't do ASR as well as Lex.

	- Ex: understanding that a second statement relates to the first.
- Build **understanding** into your **application**
- Scales, Integrates, Quick to deploy, Pay as you go pricing
	- Great for event driven or serverless architectures.
- Use Cases: Chatbots, Voice Assistants, Q&A Bots, Info/Enterprise Bots
- Lex provides .. **BOTS**, conversing in 1+ **languages**
- **Intent** - an **action** the user wants to perform
	- Ex: .. order a pizza, milkshake, or fries
	- When creating an **intent**, you're able to provide sample **utterances**
		- .. sample **utterances** .. ways in which an intent might be said; "**can I order**...", "**I want to order**...", "**Give me a** .."
	- .. How to fulfil the intent .. **lambda** integration
		- // If Lex understands that you do want to order a pizza, it needs to have some way of initiating that pizza ordering process. And often this is using Lambda. Good for event-driven architectures.

	- A **slot** is like a **parameter** for an **intent**. Pieces of information Lex needs to gain from an interaction with a user.

If you want to provide interactive **voice assistance** via a chat or voice capable bot, then you're going to use Amazon Lex.

## Amazon Polly
- Converts **text** into "**life-like**" speech
- Text (language) => Speech (Language) **NO translation**
- Polly operates in two modes - Standard TTS, & Neural TTS
- Standard TTS = **Concatenative** (phonemes)
	- The smallest unit of sound in the English language (ex: for the letter 'A', the phoneme is '**ă**' in cat, or '**ā**' in cake)
	- Takes phonemes and uses a concatenative architecture to build speech.
- Neural TTS = **phonemes** => **spectrograms** => **vocoder** => **audio**
	- Takes phonemes, generates spectrograms. Puts spectrograms through a vocoder to generate output audio.
	- More complicated & computationally heavy, but generates much more natural sounding speech.
- Output Formats - MP3.. Ogg Vorbis .. PCM...
	- Output you chose will depend on how you want to integrate Polly with other products.
- Speech Synthesis Markup Language (**SSML**)
	- .. additional control over **how** Polly generates speech
	- .. **emphasis**
	- .. **Pronunciation**
	- .. **whispering**
	- "**Newscaster**" speaking style
This product will be more often integrated with other things. Ex: you can get a WordPress plugin which allows articles on WordPress blogs to be spoken. Polly can be integrated with other AWS services where you need spoken documents. It's a niche product.

## Amazon Translate
- **Text Translation** service ... **ML** based
- Translates text from **native language** to **other languages** .. one word at a time
- **Encoder reads source** => semantic representation (**meaning**)
	- // The way you convey meaning / points differs across languages
- Decoder reads **meaning** => writes **target language**
- Attention mechanisms ensure '**meaning**' is translated
- **Auto detect** source text language
**Use Cases:**
- Multilingual user experience
- .. meeting **notes**, **posts**, **communications**, **articles**
- .. emails, **in-game** chat, customer **live chat**
- Translate **incoming data** (social media/news/communications)
- **Language-independence** for other AWS services
- .. comprehend, transcribe, polly, data stored in S3, RDS, DDB ..
- **Commonly integrates** with other services/Apps/platforms
